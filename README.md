
# Quiz Master 

An interactive multi-user quiz platform built with Flask, SQLite, and Bootstrap. This project allows administrators to create subjects, chapters, and quizzes, while users can attempt quizzes, view scores, and track progress.

##  Features

###  **Admin Panel**:
  - Add/Edit/Delete Subjects and Chapters
  - Create and manage quizzes
  - Add/Edit/Delete questions per quiz
  - View user scores and manage users

###  **User Dashboard**:
  - View upcoming quizzes
  - Start and attempt quizzes
  - Submit answers and view results

###  **Authentication**:
  - Login/Register for users
  - Role-based access (`admin` / `user`)

###  **Database**:
  - SQLite with proper foreign key relationships

---

##  Tech Stack

- **Backend**: Flask, Flask-Login, Flask-SQLAlchemy
- **Frontend**: Jinja2 Templating, Bootstrap 5
- **Database**: SQLite
